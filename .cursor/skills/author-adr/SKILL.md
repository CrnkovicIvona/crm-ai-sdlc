# Author ADR

## Rules

- Record the decision, context, options, and consequences.
- Do not pretend a deferred choice was decided.
- Place files in `docs/adr/` using the numbered template.

## Steps

1. Check existing ADRs for conflicts.
2. Add `docs/adr/NNNN-title.md`.
3. Link from `docs/adr/README.md`.
