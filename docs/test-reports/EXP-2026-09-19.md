## Exploratory findings

Confidence and severity are separate.

### Mental model — login aside

**Observed:** Aside headings ADMIN user / VIEWER user and a note that
only these two test users exist “as required by the specification.”
Form is a normal email/password login.

**User might think:** These are the only bank employees; or that
pasting aside fields is the official login UX.

**Classification:** QUESTION (spec silence) + OBSERVATION (practice
demo). Confidence high. Severity (if treated as prod bank): high;
as practice app: low. Not a BUG per human intent.

### VIEWER `/new` with no explanation

**Start:** VIEWER on list. **Action:** open `/app/clients/new`.
**Observed:** URL becomes `/app/clients`; list; no toast.

**User might think:** the create page is broken or the app ignored
the URL.

**Oracle:** VIEWER must not CREATE; redirect is specified in TC-C009
style. Functionally OK.

**Classification:** IMP (clarity). Confidence high. Severity low–medium
for first-time VIEWER. More investigation: no.
