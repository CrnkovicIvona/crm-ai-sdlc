# BUG-001: Direct production URLs `/app` and `/login` return Vercel 404

- Issue: none (GitHub Issue not opened; recorded in git)
- Severity: Medium
- Status: Fixed (local/preview verified; production re-smoke pending `main`)
- Feature / AC / TC: AUTH-001 / REL-003 production smoke step 1b /
  Playwright TC-002 (`goto('/app')` expects login)
- Production escape: yes
- RCA: [BUG-001-RCA.md](BUG-001-RCA.md)

## Symptoms

Unauthenticated `GET https://crm-ai-sdlc.vercel.app/app` returns HTTP
404 (`x-vercel-error: NOT_FOUND`). The same happens for `/login` and
`/access-denied`. Client-side navigation after loading `/` works.

## Evidence

- REL-003 smoke 2026-08-23: step 1a PASS (`/`), step 1b FAIL (`/app`)
- Repeatability: 10× curl + 8× Playwright Chromium, all 404 (not flaky)
- Local Vite `npm run dev` / Playwright CI: PASS (dev server SPA fallback)
- No `vercel.json` on `main`

## Workaround

Open `https://crm-ai-sdlc.vercel.app/` only. Do not bookmark `/app` or
`/login`.

## Expected behavior

REL-003 step 1: unauthenticated `/` and `/app` show login only, not a
hosting 404.

## Root cause

Vite SPA on Vercel without rewrite to `index.html`. Direct paths are
not files, so Vercel returns 404 before React Router runs.

## Fix

Add `vercel.json` rewrite `/(.*) → /index.html` (static files still
win). See PR on `cursor/bug-001-spa-rewrite-73b9`.
