# BUG-001: Direct production URL `/login` returns Vercel 404

- Issue: none (GitHub Issue not opened; recorded in git)
- Severity: Medium
- Status: Fixed (local/preview verified; production re-smoke pending `main`)
- Feature / AC / TC: AUTH-001 / former REL-003 smoke 1b (PO removed
  that smoke step 2026-08-23) /
  unauthenticated `GET https://crm-ai-sdlc.vercel.app/login`
- Production escape: yes
- RCA: [BUG-001-RCA.md](BUG-001-RCA.md)

## Symptoms

Unauthenticated `GET https://crm-ai-sdlc.vercel.app/login` returns HTTP
404 (`x-vercel-error: NOT_FOUND`). The SPA never loads, so the login
form is not shown. `GET https://crm-ai-sdlc.vercel.app/` still returns
200 and the client can redirect to `/login`.

**Not in REL-003 smoke** (PO removed the `GET /login` step). Residual
hosting defect if someone opens `/login` directly.

## Evidence

- REL-003 smoke 2026-08-23: step 1a PASS (`/`), step 1b FAIL
  (`https://crm-ai-sdlc.vercel.app/login` → HTTP 404)
- Repeatability: curl + Playwright against `/login` on Production, 404
  (not flaky). Reconfirmed 2026-08-23: `GET /login` → 404
  `x-vercel-error: NOT_FOUND`
- Local Vite `npm run dev` / Playwright CI: PASS (dev server SPA fallback)
- No `vercel.json` on `main`

## Workaround

Open `https://crm-ai-sdlc.vercel.app/` only. Do not bookmark `/login`.

## Expected behavior

REL-003 unauthenticated smoke is `/` only. Direct `/login` should still
not 404 for users who bookmark it.

## Root cause

Vite SPA on Vercel without rewrite to `index.html`. Direct paths are
not files, so Vercel returns 404 before React Router runs.

## Fix

Add `vercel.json` rewrite `/(.*) → /index.html` (static files still
win). See PR on `cursor/bug-001-spa-rewrite-73b9`.

## Verification result

| Check                                      | Result                                |
| ------------------------------------------ | ------------------------------------- |
| `vite preview` `GET /login`                | HTTP 200 `index.html`                 |
| Playwright vs preview `GET /login`         | 200, `login-form` visible             |
| Playwright TC-002 / TC-007 / TC-008 (Vite) | 3 passed                              |
| Vitest                                     | 5 passed                              |
| Production `GET /login`                    | still **404** (rewrite not on `main`) |

REL-003 no longer gates release on `GET /login`. The 404 can still
affect bookmarked `/login` until rewrite is on Production.

## Final status

Fixed in git (this branch). Not production-verified.
