# Root cause analysis

Required for High and Critical bugs and for any production escape.

Use `docs/bugs/` RCA template. Cover:

1. What failed (user impact)
2. Timeline
3. Immediate fix vs root cause
4. Why it escaped detection (tests, process, gates)
5. Corrective actions (tests, monitoring, process)
6. Preventive actions
7. Residual risk

Do not blame. Do not close High/Critical without RCA attached or an
explicit human waiver on the Issue.
